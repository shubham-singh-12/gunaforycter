# Gunaforycter - Culinary & Drink Experience Page

A sleek, dark-themed responsive website landing page for **Gunaforycter**, featuring signature drinks and chef's special culinary menu items. Built with semantic HTML5, modern CSS3 (Flexbox & responsive typography), and Remix Icon integration.

🔗 **Live Demo:** [View Live Site](https://gunaforycter-woad.vercel.app/)

---

## ✨ Features

- **Modern Dark UI:** Premium aesthetic utilizing dark background tones (`#0a0a0a`, `#181614`) paired with rich amber accent highlights (`#ED8011`).
- **Dynamic Card Layout:** Displays signature beverages in interactive card containers with hover animations and box shadows.
- **Featured Showcase Section:** Highlighted "Chef's Special" dish spotlight complete with detailed descriptions and CTA buttons.
- **Fluid Responsive Typography:** Uses CSS `clamp()` and media queries to ensure text scales across mobile, tablet, and desktop views.
- **Vector Icons:** Integrates Remix Icon CDN for social media handles and navigation arrows.
